# WiangChaiSubdistrictMunicipalityLearningCenter-web

เว็บไซต์ต้นแบบศูนย์เรียนรู้ฯ เทศบาลตำบลเวียงชัย

## ไฟล์
- `index.html` หน้าเว็บหลัก
- `style.css` รูปแบบและ Responsive
- `script.js` เมนู สไลด์ สมุดเยี่ยมชม และลายเซ็น

## หมายเหตุ
สมุดเยี่ยมชมในต้นแบบใช้ `localStorage` จึงเก็บเฉพาะในเบราว์เซอร์ของผู้ใช้นั้น ๆ
หากต้องการใช้งานจริงหลายเครื่อง ให้เชื่อม Google Apps Script + Google Sheets เป็นฐานข้อมูล


## ระบบหลังบ้าน (ต้นแบบ)
เปิด `admin.html` เพื่อเข้าสู่ระบบเจ้าหน้าที่

**บัญชีทดสอบ:** `admin`  
**รหัสผ่านทดสอบ:** `Admin1234`

> สำคัญ: GitHub Pages เป็น Static Hosting ดังนั้นระบบล็อกอินในชุดนี้เป็นเพียงต้นแบบฝั่งหน้าเว็บ ไม่ใช่ระบบรักษาความปลอดภัยสำหรับใช้งานจริง และข้อมูลสมุดเยี่ยมชมยังอยู่ใน browser ของผู้ใช้แต่ละเครื่อง
>
> สำหรับใช้งานจริง แนะนำเชื่อม Google Apps Script + Google Sheets หรือ Supabase เพื่อทำ Authentication, ฐานข้อมูล, การอัปโหลดไฟล์ และสิทธิ์ Admin/เจ้าหน้าที่

### ความสามารถของหลังบ้านต้นแบบ
- แดชบอร์ดและสถิติ
- ดู/ค้นหาสมุดเยี่ยมชม
- แสดงลายเซ็น
- ส่งออกสมุดเยี่ยมชมเป็น CSV
- พิมพ์/บันทึกรายงานแดชบอร์ดและสมุดเยี่ยมชมเป็น PDF ผ่านหน้าพิมพ์ของเบราว์เซอร์
- เมนูจัดการข่าว รูปภาพ เอกสาร และเนื้อหาเว็บไซต์ (เป็นโครง UI)
